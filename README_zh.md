# 中文导读

这个公开项目汇集 Memory Evidence Benchmark 的 v0.1–v0.5。仓库沿用 CommonSense Veto 项目名，但这些实验尚未证明任何否决或治理机制有效。

研究问题是：助手能否分清过去建议与用户确认、临时状态与长期偏好、旧事实与当前有效条件，以及评估建议与执行授权。

## 先看结果，再看边界

- v0.1：24 个状态判断全部正确；严格答案与证据集合评分 21/24。三处差异是证据引用集合争议，不是已经证实的记忆错误。
- v0.2：32 个判断全部正确，严格 29/32。新增 8 个旅行案例通过；不能因总比例上升就说模型进步。
- v0.3：16 个开放题，显式请求 Medium 和 High 各一轮，均 16/16 通过既定语义标准。小样本与重复题不支持两档等效结论。
- v0.4：50 个实际生成回合、16 个评分终点，不能称为 50 道独立题。主组 14 点四项全通过；补充两点选路正确，但额外细节证据不足，保守扣分且需人工复核。不能把 14/16 称为“记忆正确率”。
- v0.5：六次合成文本与本地工具实验，四个只评估案例无退课尝试，两个明确授权案例成功模拟退课。没有操作真实课表，也没有复现旧 SOC 错误。

这批数据是合成诊断与初步评测，不是真实长期记忆可靠性证明，也没有干预对照组。语义评分由 AI 辅助完成，尚无独立人工复核。

## 文件入口

阅读 [英文总览](README.md)、[方法与结果](docs/METHODS_AND_RESULTS.md)、[局限](docs/LIMITATIONS.md)、[复现说明](docs/REPRODUCIBILITY.md)。各版本目录保留中文题目、完整回答和结果说明。原始包的早期说明具有历史时点，不应覆盖后续真实运行报告。

公开副本清理了私人路径、会话标识和申请材料相关的非研究段落。源归档未改，模型不重跑；处理记录见 [PUBLIC_DATA](docs/PUBLIC_DATA.md)。历史清单中的旧哈希仍描述旧文件，当前公开文件应以根目录 `PUBLIC_MANIFEST.json` 为准。

在仓库根目录执行 `python3 scripts/verify_release.py` 和 `python3 scripts/review_saved_results.py` 可以离线核对完整性和已有成绩，不需要密钥，也不调用模型。后者不能替代人工语义复核。尚未选择许可证。
